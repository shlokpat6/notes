# Computer Hardware
- Storage
    - HDD(Hard Drives)
        - Mechanical spinning disks
        - Very slow by today’s standards
        - Still used for:
            - Cheap bulk storage
            - Backups
            - Servers / archives
    - SSD(Solid State Drives)
        - No moving parts
            - Quieter, Durable
        - Faster
        - Standard today
    - SSD Specification
        - Form factor- physical shape and size of the drive- does not indicate speed difference
            - 2.5
            - M.2
        - Interface/protocol- how the drive talks to the motherboard
            - SATA
            - PCIE/NVMe
                - PCIE is the interface(i.e. the path the type of connector)
                    - PCIe 3.0 → good
                    - PCIe 4.0 → fast
                    - PCIe 5.0 → very fast (cutting-edge)
                - NVMe is the protocol
    - The common types
        - 2.5 inch SATA SSD
            - Not as common in newer setups
        - M.2 SATA SSD
            - Not as common
        - M.2 NVMe SSD
            - The standard today
            - Much faster
- RAM(Random Access Memory)- System memory
    - What it is
        - Temporary working space for your CPU
        - Cleared when you shut down
        - Directly affects multitasking, responsiveness
    - Types of RAM
        - DDR (Double Data Rate)
            - The main standard
            - Types
                - DDR4 → older, still common
                - DDR5 → current standard (faster, more efficient)
            - Used heavily by modern systems from Intel and AMD platforms
        - LPDDR (laptop-optimized DDR)
            - LPDDR4X (older)
            - LPDDR5 / LPDDR5X(newer)
            - How it compares to DDR
                - Very low power usage → better battery life
                - Higher efficiency
                - Almost always soldered (NOT upgradeable)
            - Found in 
                - Thin laptops
                - Ultrabooks
                - Many modern ARM systems (like Snapdragon laptops)
                - AI-focused chips (like Ryzen AI / Core Ultra / Snapdragon X) rely heavily on fast LPDDR memory
    - RAM Specification
        - Capacity
            - 8GB → bare minimum (light use only)
            - 16GB → sweet spot
            - 32GB → heavy multitasking / creative work
            - 64GB+ → professional workloads
        - Speed (MT/s or MHz)
            - DDR4: ~3200 MT/s typical
            - DDR5: ~4800–6400+ MT/s
            - Higher = faster data movement
                - But diminishing returns in real use
        - Channels
            - Single-channel
                - One memory stick
                - Lower performance
            - Dual-channel
                - Two sticks working together
                    - Have to be of the same type
                - Much better bandwidth as more pathways for data travel
            - This often matters MORE than raw speed
                - More channels = more data pathways
                - So 2 8gb sticks are better than 1 16 gb stick
- CPUs
    - Intel Chip Naming Conventions
        - Older style- Ended this with the 14th gen in 2023
            - Example: Intel Core i7-13700K
            - Breakdown
                - Core i7 → Performance tier
                    - i3 = entry
                    - i5 = mid-range
                    - i7 = high-end
                    - i9 = enthusiast
                - 13 → Generation (13th gen, aka Raptor Lake)
                - 700 → SKU within that generation (higher = better within tier)
                - K → Suffix (special features)
                    - K = unlocked for overclocking
                    - F = no integrated graphics
                    - U = ultra-low power (laptops)
                    - H = high-performance laptop
                    - T = power-optimized desktop
        - Newer Style- 2 series(Core Ultra and Core)- competes with the ryzen AI lineup
            - Core Ultra- 1st gen in 2023
                - Example: Intel Core Ultra 7 155H
                - Breakdown
                    - “Ultra” = newer architecture (Meteor Lake and beyond)
                        - Focused on
                            - AI acceleration (NPUs)
                            - Efficiency improvements
                            - Chiplet design
                    - 7  -> performance tier
                        - 5 = mid-range
                        - 7 = high-end
                        - 9 = enthusiast
                    - 1 → Generation
                    - 55 → SKU within that generation (higher = better within tier)
                    - H → Suffix (special features)
                        - K = unlocked for overclocking
                        - F = no integrated graphics
                        - U = ultra-low power (laptops)
                        - H = high-performance laptop
                        - T = power-optimized desktop
            - Core- 1st gen in 2024- competes with the ryzen lineup
                - Example: Intel Core 7 150U
                - Breakdown
                    - Focused on 
                        - Lower power (thin laptops)
                        - Less advanced architectures than Ultra
                        - No “premium AI push” like Ultra chips
                    - 7  -> performance tier
                        - 3 = entry-level
                        - 5 = mid-range
                        - 7 = high-end
                        - 9 = enthusiast
                    - 1 → Generation
                    - 50→ SKU within that generation (higher = better within tier)
                    - H → Suffix (special features)
                        - K = unlocked for overclocking
                        - F = no integrated graphics
                        - U = ultra-low power (laptops)
                        - H = high-performance laptop
                        - T = power-optimized desktop
    - AMD Chip Naming Conventions
        - Long running series but likely phased out- basically competes against the intel core lineup
            - Example: AMD Ryzen 7 7840U
            - Breakdown:
                - Ryzen 7 → Performance tier
                    - Ryzen 3 / 5 / 7 / 9
                - 7 → Model year (2023 generation)
                    - 9 is the latest(2025)
                - 8 → Performance level within that generation
                - 4 → Architecture (Zen 4 in this case)
                    - Problem is that something in the same model year can have a different architecture
                        - 2 is outdated
                        - 3 is okay
                - 0 → Minor variant
                - U → Power class
                    - U = ultrathin laptops
                    - H = high-performance laptops
                    - HX = extreme performance
                    - G = integrated graphics focus (desktop APUs)
        - New AI lineup meant to compete with Intel Core Ultra and Snapdragon X
            - Example: Ryzen AI 7 350
            - Breakdown:
                - Ryzen AI → new AI-focused branding
                - 7 → performance tier
                    - 5 = mid-range
                    - 7 = high-end
                    - 9 = flagship
                - 300 → generation
                    - 300 = current (Zen 5 era)
                    - 400 = next (refresh / newer)
                - 50 (in 350) → SKU level (higher = better)
- Unified Memory
    - On many newer higher end windows laptops and all macbooks, there is unified memory    
        - The CPU, GPU, and NPU shared a single pool of memory
            - Compared to tradtional layout where there was seperate RAM for CPUs and VRAM GPUs
        - The bandwith for the unified memory is higher than RAM and on par with VRAM
        - Because the GPU has access to significantly more memory, it makes unified memory devices great for running local AI for inference
